1. Where Monday left us

A function that reads one field of a record:

getx := λr:{x:int}. r.x

And the program we want to run: getx applied to a record that has an x, and a y besides.

getx {x = 1, y = 2}

Nothing can go wrong: getx only reads x, and the record has one. So the judgement we want is the root of a derivation tree, and we start building it from the root up.

The rules we have for it: an application, and a record literal.

\[\frac{\Gamma \vdash e_1 : \tau_1 \to \tau_2 \qquad \Gamma \vdash e_2 : \tau_1}{\Gamma \vdash e_1\, e_2 : \tau_2}\ \text{(T-App)}\]
\[\frac{\Gamma \vdash e_i : \tau_i \ \text{ for each } i}{\Gamma \vdash \{\ell_i = e_i\}_{i \in 1..n} : \{\ell_i{:}\tau_i\}_{i \in 1..n}}\ \text{(T-Rcd)}\]
\[ \dfrac{\class{hl-blue}{\bbox[#eef1f6,2pt]{?}}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}} \]

The judgement we want, at the root. Build the tree upward: each rule turns the goal below its line into the goals above it.

\[ \dfrac{\class{hl-blue}{\bbox[#eef1f6,2pt]{\vdash \mathtt{getx} : \tau_1 \to \mathsf{int}}} \qquad \class{hl-blue}{\bbox[#eef1f6,2pt]{\vdash \{x = 1, y = 2\} : \tau_1}}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

T-App: the term is an application. Two premises, and an argument type \(\tau_1\) we still have to find.

\[ \dfrac{\dfrac{\dfrac{\class{hl-blue}{\bbox[#eef1f6,2pt]{r{:}\{x{:}\mathsf{int}\} \vdash r : \{x{:}\mathsf{int}\}}}}{\class{hl-blue}{\bbox[#eef1f6,2pt]{r{:}\{x{:}\mathsf{int}\} \vdash r.x : \mathsf{int}}}}{\scriptstyle \text{T-Proj}}}{\class{hl-blue}{\bbox[#eef1f6,2pt]{\vdash \mathtt{getx} : \{x{:}\mathsf{int}\} \to \mathsf{int}}}}{\scriptstyle \text{T-Abs}} \qquad \class{hl-blue}{\bbox[#eef1f6,2pt]{\vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}\}}}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

Check \(\mathtt{getx}\): T-Abs, then T-Proj, then T-Var. Its type is \(\{x{:}\mathsf{int}\} \to \mathsf{int}\), so \(\tau_1 = \{x{:}\mathsf{int}\}\): the argument must have that type.

\[ \dfrac{\dfrac{\dfrac{r{:}\{x{:}\mathsf{int}\} \vdash r : \{x{:}\mathsf{int}\}}{r{:}\{x{:}\mathsf{int}\} \vdash r.x : \mathsf{int}}{\scriptstyle \text{T-Proj}}}{\vdash \mathtt{getx} : \{x{:}\mathsf{int}\} \to \mathsf{int}}{\scriptstyle \text{T-Abs}} \qquad \dfrac{\class{hl-blue}{\bbox[#eef1f6,2pt]{\{x{:}\mathsf{int}, y{:}\mathsf{int}\} \neq \{x{:}\mathsf{int}\}}}}{\vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}\}}{\scriptstyle \class{hl-blue}{\bbox[#eef1f6,2pt]{\text{T-Rcd ✗}}}}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

The argument is a record literal, and T-Rcd is the only rule for one. It gives \(\{x{:}\mathsf{int}, y{:}\mathsf{int}\}\), which is not \(\{x{:}\mathsf{int}\}\). The tree cannot be finished.

So the rules reject getx {x = 1, y = 2}: the application rule demands the argument's type be exactly the parameter's, and a record with two fields is not a record with one. The program is safe and the type system turns it away.

2. How we fixed it: subtype polymorphism

getx is fine on every record with an x:int field: \(\{x{:}\mathsf{int}\}\), \(\{x{:}\mathsf{int}, y{:}\mathsf{int}\}\), \(\{x{:}\mathsf{int}, y{:}\mathsf{bool}, z{:}\mathsf{int}\}\), … One function, many types. That is polymorphism, and this flavor of it is subtype polymorphism: a relation \(\sigma <: \tau\) on types, read "a \(\sigma\) is safe wherever a \(\tau\) is expected", and one typing rule that uses it.

\[\frac{\Gamma \vdash e : \sigma \qquad \sigma <: \tau}{\Gamma \vdash e : \tau}\ \text{(T-Sub)}\]

Subsumption: a term of type \(\sigma\) also has every type \(\tau\) above it. Then the rules for \(<:\) itself. A record with more fields can be used where one with fewer is expected, so it is a subtype of it:

\[\frac{J \subseteq I}{\{\ell_i{:}\tau_i\}_{i \in I} <: \{\ell_j{:}\tau_j\}_{j \in J}}\ \text{(S-RcdWidth)}\]

And every type is a subtype of itself:

\[\frac{}{\tau <: \tau}\ \text{(S-Refl)}\]

The derivation, again

Same root, same first two steps. The step that failed now has a different rule to reach for.

\[ \dfrac{\vdash \mathtt{getx} : \tau_1 \to \mathsf{int} \quad \vdash \{x = 1, y = 2\} : \tau_1}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

T-App, as before.

\[ \dfrac{\dfrac{}{\vdash \mathtt{getx} : \{x{:}\mathsf{int}\} \to \mathsf{int}}{\scriptstyle \text{(above)}} \quad \vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}\}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

\(\mathtt{getx}\) has the type we found above, so \(\tau_1 = \{x{:}\mathsf{int}\}\) as before. The argument premise is where we got stuck.

\[ \dfrac{\dfrac{}{\vdash \mathtt{getx} : \{x{:}\mathsf{int}\} \to \mathsf{int}}{\scriptstyle \text{(above)}} \quad \dfrac{\class{hl-blue}{\bbox[#eef1f6,2pt]{\vdash \{x = 1, y = 2\} : \sigma}} \qquad \class{hl-blue}{\bbox[#eef1f6,2pt]{\sigma <: \{x{:}\mathsf{int}\}}}}{\vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}\}}{\scriptstyle \class{hl-blue}{\bbox[#eef1f6,2pt]{\text{T-Sub}}}}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

T-Sub instead of T-Rcd: give the argument some type \(\sigma\), and show \(\sigma <: \{x{:}\mathsf{int}\}\). We get to choose \(\sigma\).

\[ \dfrac{\dfrac{}{\vdash \mathtt{getx} : \{x{:}\mathsf{int}\} \to \mathsf{int}}{\scriptstyle \text{(above)}} \quad \dfrac{\dfrac{\class{hl-blue}{\bbox[#eef1f6,2pt]{\vdash 1 : \mathsf{int} \quad \vdash 2 : \mathsf{int}}}}{\class{hl-blue}{\bbox[#eef1f6,2pt]{\vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}, y{:}\mathsf{int}\}}}}{\scriptstyle \class{hl-blue}{\bbox[#eef1f6,2pt]{\text{T-Rcd}}}} \quad \class{hl-blue}{\bbox[#eef1f6,2pt]{\{x{:}\mathsf{int}, y{:}\mathsf{int}\} <: \{x{:}\mathsf{int}\}}}}{\vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}\}}{\scriptstyle \text{T-Sub}}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

Choose \(\sigma = \{x{:}\mathsf{int}, y{:}\mathsf{int}\}\): the type T-Rcd was always able to give. The left premise closes.

\[ \dfrac{\dfrac{}{\vdash \mathtt{getx} : \{x{:}\mathsf{int}\} \to \mathsf{int}}{\scriptstyle \text{(above)}} \quad \dfrac{\dfrac{\vdash 1 : \mathsf{int} \quad \vdash 2 : \mathsf{int}}{\vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}, y{:}\mathsf{int}\}}{\scriptstyle \text{T-Rcd}} \quad \dfrac{}{\class{hl-blue}{\bbox[#eef1f6,2pt]{\{x{:}\mathsf{int}, y{:}\mathsf{int}\} <: \{x{:}\mathsf{int}\}}}}{\scriptstyle \class{hl-blue}{\bbox[#eef1f6,2pt]{\text{S-RcdWidth}}}}}{\vdash \{x = 1, y = 2\} : \{x{:}\mathsf{int}\}}{\scriptstyle \text{T-Sub}}}{\vdash \mathtt{getx}\ \{x = 1, y = 2\} : \mathsf{int}}{\scriptstyle \text{T-App}} \]

The right premise closes by S-RcdWidth, with \(I = \{x, y\}\) and \(J = \{x\}\). Every leaf is an axiom: the program types.

Where S-Refl comes in: not in this tree. But now that T-Sub is a rule, it can be applied at any node, with \(\sigma = \tau\) and S-Refl for the side condition, and nothing changes. The tree above is no longer the only derivation of its root. Keep that in mind; it comes back when we try to turn these rules into a checker.

3. Can a program find this tree?

A derivation exists. Could a program have found it? Two weeks ago you wrote one that finds derivations in this language without subtyping: HW4's typeof. Build it again, from the rules, one clause at a time.

                       if typeof Γ e₂ = τ₁ then τ₂ else fail

The same pattern every time. The term form in the conclusion is the clause's pattern. Each premise is a recursive call on a subterm. Whatever two premises share, here \(\tau_1\) in T-App, becomes a test. Rules like this are called syntax-directed: one rule per form, and the premises fixed by the conclusion. That is why HW4 was possible: the clause is the rule read bottom-up, and the derivation is a function of the term.

⇒ Soundness. If \(\Gamma \vdash_{\mathsf a} e : \tau\) then \(\Gamma \vdash e : \tau\). Induction on the algorithmic derivation; each rule, as a declarative derivation.

\[ \dfrac{x{:}\tau \in \Gamma}{\Gamma \vdash_{\mathsf a} x : \tau}{\scriptstyle \text{TA-Var}} \]
\[ \dfrac{x{:}\tau \in \Gamma}{\Gamma \vdash_{\mathsf a} x : \tau}{\scriptstyle \text{TA-Var}}\ \mapsto\ \dfrac{x{:}\tau \in \Gamma}{\Gamma \vdash x : \tau}{\scriptstyle \text{T-Var}} \]

The same rule; the premises are the inductive hypothesis.

\[ \dfrac{\Gamma, x{:}\tau_1 \vdash_{\mathsf a} e : \tau_2}{\Gamma \vdash_{\mathsf a} \lambda x{:}\tau_1.\, e : \tau_1 \to \tau_2}{\scriptstyle \text{TA-Abs}} \]
\[ \dfrac{\Gamma, x{:}\tau_1 \vdash_{\mathsf a} e : \tau_2}{\Gamma \vdash_{\mathsf a} \lambda x{:}\tau_1.\, e : \tau_1 \to \tau_2}{\scriptstyle \text{TA-Abs}}\ \mapsto\ \dfrac{\Gamma, x{:}\tau_1 \vdash e : \tau_2}{\Gamma \vdash \lambda x{:}\tau_1.\, e : \tau_1 \to \tau_2}{\scriptstyle \text{T-Abs}} \]

The same rule; the premises are the inductive hypothesis.

The same rule; the premises are the inductive hypothesis.

\[ \dfrac{\Gamma \vdash_{\mathsf a} e : \{\ell_i{:}\tau_i\}}{\Gamma \vdash_{\mathsf a} e.\ell_j : \tau_j}{\scriptstyle \text{TA-Proj}} \]

The same rule; the premises are the inductive hypothesis.

\[ \dfrac{\Gamma \vdash_{\mathsf a} e_1 : \tau_1 \to \tau_2 \quad \Gamma \vdash_{\mathsf a} e_2 : \tau \quad \tau <:_{\mathsf a} \tau_1}{\Gamma \vdash_{\mathsf a} e_1\, e_2 : \tau_2}{\scriptstyle \text{TA-App}} \]

The check becomes one T-Sub on the argument; the premises are the inductive hypothesis, and \(<:\) is the subtyping theorem.

⇐ Completeness, minimal typing. If \(\Gamma \vdash e : \tau\) then \(\Gamma \vdash_{\mathsf a} e : \sigma\) for some \(\sigma <: \tau\): the algorithm's type is below every declarative one. Induction on the declarative derivation; one case per rule.

\[ \dfrac{x{:}\tau \in \Gamma}{\Gamma \vdash x : \tau}{\scriptstyle \text{T-Var}} \]
\[ \dfrac{x{:}\tau \in \Gamma}{\Gamma \vdash x : \tau}{\scriptstyle \text{T-Var}}\ \mapsto\ \dfrac{x{:}\tau \in \Gamma}{\Gamma \vdash_{\mathsf a} x : \tau \ \text{ and } \ \tau <: \tau}{\scriptstyle \text{TA-Var}} \]

The same rule; the same type, below itself by reflexivity.

\[ \dfrac{\Gamma, x{:}\tau_1 \vdash e : \tau_2}{\Gamma \vdash \lambda x{:}\tau_1.\, e : \tau_1 \to \tau_2}{\scriptstyle \text{T-Abs}} \]
\[ \dfrac{\Gamma, x{:}\tau_1 \vdash e : \tau_2}{\Gamma \vdash \lambda x{:}\tau_1.\, e : \tau_1 \to \tau_2}{\scriptstyle \text{T-Abs}}\ \mapsto\ \dfrac{\Gamma, x{:}\tau_1 \vdash_{\mathsf a} e : \sigma_2 \quad \sigma_2 <: \tau_2 \ \text{(IH)}}{\Gamma \vdash_{\mathsf a} \lambda x{:}\tau_1.\, e : \tau_1 \to \sigma_2 \ \text{ and } \ \tau_1 \to \sigma_2 <: \tau_1 \to \tau_2}{\scriptstyle \text{TA-Abs, S-Arrow}} \]

The body gets a type below \(\tau_2\), so the arrow is below \(\tau_1 \to \tau_2\): S-Arrow, with reflexivity on the argument.

\[ \dfrac{\Gamma \vdash e_1 : \tau_1 \ \cdots\ \Gamma \vdash e_n : \tau_n}{\Gamma \vdash \{\ell_i = e_i\} : \{\ell_i{:}\tau_i\}}{\scriptstyle \text{T-Rcd}} \]
\[ \dfrac{\Gamma \vdash e_1 : \tau_1 \ \cdots\ \Gamma \vdash e_n : \tau_n}{\Gamma \vdash \{\ell_i = e_i\} : \{\ell_i{:}\tau_i\}}{\scriptstyle \text{T-Rcd}}\ \mapsto\ \dfrac{\Gamma \vdash_{\mathsf a} e_i : \sigma_i \quad \sigma_i <: \tau_i \ \text{(IH, each } i)}{\Gamma \vdash_{\mathsf a} \{\ell_i = e_i\} : \{\ell_i{:}\sigma_i\} \ \text{ and } \ \{\ell_i{:}\sigma_i\} <: \{\ell_i{:}\tau_i\}}{\scriptstyle \text{TA-Rcd, S-RcdDepth}} \]

Each field gets a type below \(\tau_i\); by depth the record type is below \(\{\ell_i{:}\tau_i\}\).

\[ \dfrac{\Gamma \vdash e : \{\ell_i{:}\tau_i\}}{\Gamma \vdash e.\ell_j : \tau_j}{\scriptstyle \text{T-Proj}} \]
\[ \dfrac{\Gamma \vdash e : \{\ell_i{:}\tau_i\}}{\Gamma \vdash e.\ell_j : \tau_j}{\scriptstyle \text{T-Proj}}\ \mapsto\ \dfrac{\Gamma \vdash_{\mathsf a} e : \{k_l{:}\sigma_l\} \quad \{k_l{:}\sigma_l\} <: \{\ell_i{:}\tau_i\} \ \text{(IH)}}{\Gamma \vdash_{\mathsf a} e.\ell_j : \sigma_l \ \text{ and } \ \sigma_l <: \tau_j}{\scriptstyle \text{TA-Proj}} \]

A record type below \(\{\ell_i{:}\tau_i\}\) still has the field \(\ell_j\), at some \(\sigma_l <: \tau_j\): that is what SA-Rcd says.

\[ \dfrac{\Gamma \vdash e : \sigma \quad \sigma <: \tau}{\Gamma \vdash e : \tau}{\scriptstyle \text{T-Sub}} \]
\[ \dfrac{\Gamma \vdash e : \sigma \quad \sigma <: \tau}{\Gamma \vdash e : \tau}{\scriptstyle \text{T-Sub}}\ \mapsto\ \dfrac{\Gamma \vdash_{\mathsf a} e : \sigma\prime \quad \sigma\prime <: \sigma \ \text{(IH)} \quad \sigma <: \tau}{\Gamma \vdash_{\mathsf a} e : \sigma\prime \ \text{ and } \ \sigma\prime <: \tau}{\scriptstyle \text{S-Trans}} \]

The algorithm does nothing at this node. The inductive hypothesis gives a type below \(\sigma\); transitivity puts it below \(\tau\).

\[ \dfrac{\Gamma \vdash e_1 : \tau_1 \to \tau_2 \quad \Gamma \vdash e_2 : \tau_1}{\Gamma \vdash e_1\, e_2 : \tau_2}{\scriptstyle \text{T-App}} \]

4. Type safety

Same dynamics as HW4: call-by-value, two redexes.

\[ (\lambda x{:}\tau.\, e)\ v \longrightarrow e[x \mapsto v] \qquad\qquad \{\ell_i = v_i\}.\ell_j \longrightarrow v_j \]

Progress and preservation, as in Lecture 13. For \(\vdash_{\mathsf a}\): one rule per term form, so inverting a derivation is reading its last rule.

Canonical forms. A closed value's algorithmic type says what it is; only TA-Abs gives an arrow type, only TA-Rcd a record type.

\[ \vdash_{\mathsf a} v : \tau_1 \to \tau_2 \ \Longrightarrow\ v = \lambda x{:}\tau_1.\, e \qquad\qquad \vdash_{\mathsf a} v : \{\ell_i{:}\tau_i\} \ \Longrightarrow\ v = \{\ell_i = v_i\} \]

Progress

Theorem (progress). If \(\vdash_{\mathsf a} e : \tau\) then \(e\) is a value or \(e \longrightarrow e'\). Induction on the derivation; the same proof as for STLC, with canonical forms doing the same job.

  • Case \(e = x\). Impossible: the context is empty.
  • Case \(e = \lambda x{:}\tau_1.\, e'\). A value.
  • Case \(e = e_1\, e_2\).
    • \(e_1\) steps: so does \(e_1\, e_2\).
    • \(e_1\) a value, \(e_2\) steps: so does \(e_1\, e_2\).
    • both values: canonical forms, \(e_1 = \lambda x{:}\tau_1.\, e'\), so β fires.
  • Case \(e = \{\ell_i = e_i\}\).
    • some \(e_k\) steps (the first one): so does \(\{\ell_i = e_i\}\).
    • all values: a value.
  • Case \(e = e'.\ell_j\).
    • \(e'\) steps: so does \(e'.\ell_j\).
    • \(e'\) a value: canonical forms, \(e' = \{\ell_i = v_i\}\) with the field \(\ell_j\), so projection fires. \(\square\)

Preservation: the old statement is false

Lecture 13: if \(\vdash_{\mathsf a} e : \tau\) and \(e \longrightarrow e\prime\) then \(\vdash_{\mathsf a} e\prime : \tau\)?

\[ \vdash_{\mathsf a} (\lambda r{:}\{x{:}\mathsf{int}\}.\, r)\ \{x = 1, y = 2\} : \{x{:}\mathsf{int}\} \]

A term and its algorithmic type: the function returns its argument, of type \(\{x{:}\mathsf{int}\}\).

\[ \begin{gathered} \vdash_{\mathsf a} (\lambda r{:}\{x{:}\mathsf{int}\}.\, r)\ \{x = 1, y = 2\} : \{x{:}\mathsf{int}\} \\[10pt] \longrightarrow\ \{x = 1, y = 2\} \end{gathered} \]

One β step.

\[ \begin{gathered} \vdash_{\mathsf a} (\lambda r{:}\{x{:}\mathsf{int}\}.\, r)\ \{x = 1, y = 2\} : \{x{:}\mathsf{int}\} \\[10pt] \longrightarrow\ \{x = 1, y = 2\} \qquad \vdash_{\mathsf a} \{x = 1, y = 2\} : \class{hl-blue}{\bbox[#eef1f6,2pt]{\{x{:}\mathsf{int}, y{:}\mathsf{int}\}}} \end{gathered} \]

The result's algorithmic type is \(\{x{:}\mathsf{int}, y{:}\mathsf{int}\}\). Not \(\{x{:}\mathsf{int}\}\).

So the statement has to allow a subtype:

\[ \text{If } \vdash_{\mathsf a} e : \tau \text{ and } e \longrightarrow e\prime \text{ then } \vdash_{\mathsf a} e\prime : \tau\prime \text{ for some } \class{hl-blue}{\bbox[#eef1f6,2pt]{\tau\prime <: \tau}} \]

Substitution

Lemma (substitution, up to subtyping). If \(\Gamma, x{:}\sigma \vdash_{\mathsf a} e : \tau\) and \(\vdash_{\mathsf a} v : \sigma\prime\) with \(\sigma\prime <: \sigma\), then \(\Gamma \vdash_{\mathsf a} e[x \mapsto v] : \tau\prime\) for some \(\tau\prime <: \tau\). Needed in the β case of preservation, where the argument's type is only a subtype of the parameter's. Induction on \(e\); the application case is the completeness case again.

Preservation

The algorithm returns one type, and the example showed that type can change along a step. So the theorem asks for a subtype of the original type, not the type itself.

Theorem (preservation, up to subtyping). If \(\vdash_{\mathsf a} e : \tau\) and \(e \longrightarrow e'\) then \(\vdash_{\mathsf a} e' : \tau'\) for some \(\tau' <: \tau\). Induction on the step.

  • Case \((\lambda x{:}\sigma.\, e)\ v \longrightarrow e[x \mapsto v]\).
    • Hypotheses:
      • \(\vdash_{\mathsf a} (\lambda x{:}\sigma.\, e)\ v : \tau\) — given.
      • TA-App, the only rule for an application:
        • \(\vdash_{\mathsf a} \lambda x{:}\sigma.\, e : \sigma \to \tau\)
        • \(\vdash_{\mathsf a} v : \sigma'\)
        • \(\sigma' <:_{\mathsf a} \sigma\)
      • \(x{:}\sigma \vdash_{\mathsf a} e : \tau\) — TA-Abs, the only rule for a λ.
    • Goal: \(\vdash_{\mathsf a} e[x \mapsto v] : \tau'\) for some \(\tau' <: \tau\).
    • Proof: using \(x{:}\sigma \vdash_{\mathsf a} e : \tau\), \(\vdash_{\mathsf a} v : \sigma'\) and \(\sigma' <: \sigma\), by the substitution lemma we have \(\vdash_{\mathsf a} e[x \mapsto v] : \tau'\) for some \(\tau' <: \tau\).
  • Case \(\{\ell_i = v_i\}.\ell_j \longrightarrow v_j\).
    • Hypotheses:
      • \(\vdash_{\mathsf a} \{\ell_i = v_i\}.\ell_j : \tau\) — given.
      • TA-Proj:
        • \(\vdash_{\mathsf a} \{\ell_i = v_i\} : \{\ell_i{:}\tau_i\}\)
        • \(\tau = \tau_j\)
      • \(\vdash_{\mathsf a} v_i : \tau_i\) for each \(i\) — TA-Rcd.
    • Goal: \(\vdash_{\mathsf a} v_j : \tau'\) for some \(\tau' <: \tau_j\).
    • Proof: using \(\vdash_{\mathsf a} v_j : \tau_j\), take \(\tau' = \tau_j\); by reflexivity, \(\tau_j <: \tau_j\).
  • Case \(E[r] \longrightarrow E[r']\) with \(r \longrightarrow r'\).
    • Hypotheses:
      • \(\vdash_{\mathsf a} E[r] : \tau\) — given.
      • \(\vdash_{\mathsf a} r : \rho\) — the redex has a type of its own inside the derivation.
      • Inductive hypothesis on \(r \longrightarrow r'\):
        • \(\vdash_{\mathsf a} r' : \rho'\)
        • \(\rho' <: \rho\)
    • Goal: \(\vdash_{\mathsf a} E[r'] : \tau'\) for some \(\tau' <: \tau\).
    • Proof: by cases on \(E\), using \(\vdash_{\mathsf a} r' : \rho'\) and \(\rho' <: \rho\) in place of \(r\)'s typing. Function position: by S-Arrow, \(\rho'\) is an arrow with parameter type above \(\tau_1\), so by transitivity the check still passes. Argument position: by transitivity, \(\rho' <: \rho <:_{\mathsf a} \tau_1\). Record field: by depth, the record type is below the old one. Projection: by SA-Rcd, the field is still there. In each case \(\vdash_{\mathsf a} E[r'] : \tau'\) with \(\tau' <: \tau\). \(\square\)

Back to the declarative system

In review, three theorems:

  • Minimal types. If \(\Gamma \vdash e : \tau\) then \(\Gamma \vdash_{\mathsf a} e : \sigma\) for some \(\sigma <: \tau\).

  • Soundness. If \(\Gamma \vdash_{\mathsf a} e : \tau\) then \(\Gamma \vdash e : \tau\).
