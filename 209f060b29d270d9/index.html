A self-contained tutorial

PRACBPV from three ingredients

PRACBPV is call-by-push-value (CBPV) with algebraic effects, in which every computation runs at a world, and some effects move the computation to a different world: allocating a memory cell, or letting one step of time pass. This tutorial derives its syntax and its denotational semantics from three pieces of existing mathematics.

Parameterized algebraic theoriessay what an operation looks like: it takes parameters (such as a memory cell) and continuations, and a continuation may bind new parameters. (Part I)
Presheaf polynomialssay what operations and binders denote: functors on presheaves built from sums and products, where every position remembers which world it lives at. (Part II)
Parametric right adjointsare the universal property of those polynomials. That property is what turns "work behind a binder" into a well-behaved typing rule, and what makes substitution work. (Part III)

Parts IV and V assemble the three into PRACBPV's syntax and its semantics. Two running examples are used throughout: local state, where a world is a set of allocated cells, and guarded recursion, where a world is a number of steps left. With only one world, everything collapses to the plain CBPV with algebraic effects of the POPL paper.

Part 0

Worlds and presheaves

The setting everything else lives in.

Worlds

Fix a category $\W$ whose objects are called worlds. A map $f : w \to w'$ says that $w'$ is a possible future of $w$: whatever makes sense at $w$ can be carried forward to $w'$ along $f$.

Local state: $\W = \Inj$

A world is a number $n$, read as "$n$ cells allocated", the cells being $\Fin\,n = \{0, \ldots, n-1\}$. A map $n \to m$ is an injection $\Fin\,n \hookrightarrow \Fin\,m$: old cells survive, possibly renamed, and new cells may appear. Cells are never deleted.

Guarded: $\W = \omega^{op}$

A world is a number $n$, read as "$n$ steps left". There is exactly one map $n \to m$ when $m \le n$, and none otherwise: time only runs down.

Presheaves

A presheaf is a functor $X : \W \to \Set$. $X(w)$ is the set of things of kind $X$ that exist at world $w$, and $X(f) : X(w) \to X(w')$ carries them forward. A map of presheaves $X \to Y$ is a natural transformation: a function $X(w) \to Y(w)$ at every world, commuting with carrying forward. Presheaves form a category $\Psh$.

This development writes presheaves covariantly, as functors out of $\W$, so "presheaf on $\W$" here is what is often called a presheaf on $\W^{op}$.

Local state

The presheaf of cells: $X(n) = \Fin\,n$, carried forward by applying the injection.

Guarded

Streams of bits: $X(n)$ is the lists of length $n$ (the first $n$ bits), carried forward by truncating.

Representables, Yoneda, and maps out of sums

The representable presheaf at $w$ is $y\,w = \W[w, -]$. Its elements at $t$ are the ways $t$ is a future of $w$. Think of $y\,w$ as "a single point at world $w$". Two facts get used constantly:

$$\Psh(y\,w, X) \cong X(w) \qquad\qquad \Psh\Big(\sum_{p \in P} y\,v_p,\ X\Big) \cong \prod_{p \in P} X(v_p)$$

A map out of a single point at $w$ is an element at $w$ (Yoneda). A map out of several points, the first at $v_1$, the second at $v_2$, and so on, is one element at each of their worlds.

Part I

Parameterized algebraic theories

What an operation looks like, syntactically. Main source: Staton, LICS 2013.

I.1 Operations in continuation-passing style

In the algebraic approach to effects (Plotkin and Power), an effect is presented by operations. An operation takes one continuation for each possible outcome, and runs one of them. Reading a bit is a binary operation:

$$x \mathbin{?} y \qquad \text{read a bit; continue as } x \text{ if it is 0, as } y \text{ if it is 1.}$$

All the continuations have the same type, and so does the whole term. An operation does not return a value of its own; it decides how to continue. This is continuation-passing style.

I.2 Parameters and binders

For local state this is not enough. Reading has to know which cell, and allocation has to hand its continuation a new cell. A parameterized algebraic theory (PAT) adds both of these.

Definition (Staton 2013, Def. 1), informally
  • Base types $\alpha, \beta, \ldots$ are kinds of parameter, such as memory cells or channel names.
  • Types are $\tau ::= \alpha \mid [\tau_1, \ldots, \tau_n]$. For example $[\alpha, \alpha]$ is a computation that takes two parameters, and $[\,]$ is a computation with no parameters.
  • A function symbol $F : [\tau_1, \ldots, \tau_n]$ is an operation. Each of its arguments $\tau_i$ is one of:
    • $\alpha$: a parameter argument, e.g. the cell to read;
    • $[\alpha, \ldots, \alpha]$: a continuation argument that binds that many new parameters. $[\,]$ is a continuation that binds nothing.
  • Equations between terms, saying which programs are equal.

I.3 What a binder means in a PAT

Staton interprets a PAT in presheaves on $\Ctx_0$, the category of contexts of parameters and renamings between them. A renaming is any function on variables, so it may identify two variables. A base type is interpreted as a representable presheaf, and a continuation $[\alpha]$ as an exponential:

$$X^{[\![\alpha]\!]}(\Gamma) = X(\Gamma, a{:}\alpha).$$

Because renamings may identify variables, the bound $a$ is an ordinary variable: it may turn out to equal a cell already in $\Gamma$. The fact that allocation produces a fresh cell is therefore not built in. It is imposed by an equation, using the comparison $?_=$:

$$a{:}\alpha,\ x, y{:}[\alpha] \ \vdash\ \nu b.\,\big(x(b) \mathrel{?_{a=b}} y(b)\big) \;\equiv\; \nu b.\, y(b) \qquad (\text{new-}\nu)$$

"Comparing the new cell with any existing cell always says they differ."

I.4 What PRACBPV takes, and what it changes

PRACBPV keeps the shape of a PAT operation and changes three things about it.

  1. No equations. PRACBPV operations are lawless. Their behaviour comes from an operational semantics, an abstract machine that runs programs, rather than from equations.
  2. Freshness moves into the worlds. With $\W = \Inj$, "bind a new cell" is interpreted not as the exponential but as moving to the next world, $n \mapsto n{+}1$. The new cell is the cell $n$, which differs from every old cell by construction. No $?_=$ and no (new-$\nu$) are needed.
  3. Binders generalize to locks. "The continuation binds a new cell" becomes one instance of a more general idea:
Lock kinds and lock words, informally (precise version in II.3–II.4)

A lock kind $\kappa$ is a named way in which a continuation's world can differ from the current one. Crossing the lock moves you to a new world, possibly making some new parameters available there. Two examples:

  • $\fresh$ (local state): the new world has one more cell, and that cell is available as a parameter;
  • $\tick$ (guarded): the new world has one step fewer, and nothing new is available.

A lock word is a finite list of lock kinds, $\mu = \kappa_1 \kappa_2 \cdots \kappa_k$: the locks a continuation sits behind, crossed left to right. The empty word, written $\varepsilon$, means the continuation runs at the current world. A PAT continuation $[\alpha^m]$, which binds $m$ new cells, becomes the word $\fresh^m$, i.e. $\fresh$ repeated $m$ times.

  • $\Ar\,o$: a set of slots, one per continuation argument.
  • $\slot\,o\,a$: for each slot $a$, the lock word its continuation sits behind.

Part II

Presheaf polynomials

What operations and lock kinds denote: functors built from sums and products, where every position remembers which world it lives at.

II.1 Polynomials on sets: shapes and positions

A polynomial functor $\Set \to \Set$ is a sum of powers:

$$T X = \sum_{s \in S} X^{P(s)}$$
  • The shapes $S$: what an element looks like with its data erased. Note $S = T\,1$.
  • The positions $P(s)$ of each shape: the places in an element of that shape where an $X$ goes.

II.2 Polynomials on presheaves: positions carry worlds

On presheaves, two things change. The set of shapes may depend on the world (at $n$ cells there are $n$ different "read cell $i$" shapes). And each position says which world its $X$ lives at.

Definition
$$T X(w) \;=\; \sum_{s \in S(w)} \ \prod_{p \in \Pos(w,s)} X\big(\sc(w,s,p)\big)$$

The data, and how each piece varies along a map of worlds $f : w \to w'$:

  • Shapes: a presheaf $S$. A shape $s$ at $w$ is carried forward to the shape $S(f)(s)$ at $w'$.
  • Positions: a set $\Pos(w,s)$ for each shape at each world. Positions go backwards: a function $\mathrm{pos}_f : \Pos(w', S(f)s) \to \Pos(w, s)$.
  • Scopes: a world $\sc(w,s,p)$ for each position. Scopes go forwards: for each $p' \in \Pos(w', S(f)s)$, a world map $\mathrm{smap}_f(p') : \sc(w, s, \mathrm{pos}_f\,p') \to \sc(w', S(f)s, p')$.

These are subject to the usual identity and composition laws. That is exactly the statement that positions and scopes together form a functor, as explained next.

Why positions go backwards. $T X(f)$ must turn an element at $w$ (one $X$ per position at $w$) into an element at $w'$ (one $X$ per position at $w'$). To fill a position $p'$ at $w'$, you look up the corresponding position $\mathrm{pos}_f\,p'$ at $w$, take the $X$ found there, and carry it forward along $\mathrm{smap}_f(p')$:

$$\big(T X(f)(s, k)\big)(p') \;=\; X(\mathrm{smap}_f\,p')\big(k(\mathrm{pos}_f\,p')\big).$$

Arities: the same data, packaged

Fix a shape $s$ at $w$. Its positions and scopes are a family of worlds, one per position, and a family of worlds names a presheaf, namely the sum of the representables at those worlds:

$$E(w,s) \;=\; \sum_{p \in \Pos(w,s)} y\big(\sc(w,s,p)\big) \qquad\text{the } \textbf{arity} \text{ of } s.$$

Read it as "one point at each position's world". By the two facts of Part 0, a map out of the arity is exactly one $X$ per position, each at its own world:

$$\Psh\big(E(w,s), X\big) \;\cong\; \prod_{p \in \Pos(w,s)} X\big(\sc(w,s,p)\big), \qquad\text{so}\qquad T X(w) \;\cong\; \sum_{s \in S(w)} \Psh\big(E(w,s), X\big).$$

So the polynomial is a family of representable functors $\Psh(E(w,s), -)$, one per shape. This is where the name "familially representable" comes from.

Definition: families of worlds, and the arity functor

$\Fam(\W)$ is the category whose objects are families of worlds: a set $I$ and a world $X_i$ for each $i \in I$, written $\sum_{i \in I} y\,X_i$. A morphism $\sum_i y\,X_i \to \sum_j y\,Y_j$ is a function $\varphi : I \to J$ together with world maps $Y_{\varphi(i)} \to X_i$. These are exactly the presheaf maps between the corresponding sums of representables.

The shapes form a category of elements $\int\! S$: objects are pairs $(w, s)$ with $s \in S(w)$; maps $(w,s) \to (w', s')$ are maps $f : w \to w'$ with $S(f)(s) = s'$. Positions and scopes are then one functor

$$E : \big(\textstyle\int S\big)^{op} \to \Fam(\W), \qquad E(w,s) = \big(\Pos(w,s),\ \sc(w,s,-)\big),$$

whose action on a map $f$ is the pair $(\mathrm{pos}_f, \mathrm{smap}_f)$. Its functoriality is the identity and composition laws above.

For category theorists: this is a polynomial in $\mathbf{Cat}$, $\W \leftarrow \int\!\Pos \to \int\!S \to \W$, where the middle map is a discrete opfibration and the right map a discrete fibration. $T$ is "pull back along the scope, take products over the positions, take sums over the shapes", and those products and sums are exactly the $\prod_p$ and $\sum_s$ of the formula. The development calls this the Poly record, and in Polynomial.agda the arity functor is the G : Functor (∫ Shapes) (Fam W) above. (Its category of elements is taken in the opposite orientation, which absorbs the ${}^{op}$.)

Base types and their values

The base types of Part I also become presheaves. Each base type $b$ comes with a presheaf $\Const_b$, its values at each world. For local state, $\Const_{\Lc}(n) = \Fin\,n$: the parameters of type "cell" at world $n$ are the $n$ cells. For an operation $o$, write $\Par_o(w) = \prod_{b \in \params\,o} \Const_b(w)$ for the possible parameter tuples at $w$.

II.3 Lock kinds: one-shape polynomials

A lock kind (I.4) is a polynomial with exactly one shape, "the continuation", whose positions are the ways of crossing the lock. Its data, piece by piece:

A lock kind $\kappa$
  1. Positions $\Pos_\kappa(w)$: the ways of crossing the lock at world $w$. There may be none, one, or several.
  2. Scopes $\sc_\kappa(w,p)$: the world on the far side, when crossing in way $p$.
  3. Functoriality, as in II.2 with a single shape: $\mathrm{pos}_f : \Pos_\kappa(w') \to \Pos_\kappa(w)$, and $\mathrm{smap}_f(p') : \sc_\kappa(w, \mathrm{pos}_f\,p') \to \sc_\kappa(w', p')$. Together these give a functor $E_\kappa : \W^{op} \to \Fam(\W)$, $E_\kappa(w) = \sum_p y(\sc_\kappa(w,p))$.
  4. Strength: a world map $\iota_{w,p} : w \to \sc_\kappa(w,p)$, natural in $w$. The far side is a future of the near side, so anything that existed before the lock can be carried across it.
  5. Names: a list of base types $\vec b_\kappa$, the parameters the lock makes available, and their values on the far side, $\gen_{w,p} \in \prod_{b \in \vec b_\kappa} \Const_b(\sc_\kappa(w,p))$, natural in $w$.

Items 1–3 determine a one-shape polynomial, called the modality of $\kappa$:

$$R_\kappa X(w) = \prod_{p \in \Pos_\kappa(w)} X\big(\sc_\kappa(w,p)\big)$$

An $X$ at every world you could reach by crossing a $\kappa$-lock from $w$.

Local state: $\fresh$

One way to cross, $\Pos(n) = \{\ast\}$, and $\sc(n) = n{+}1$.

Along an injection $f : n \hookrightarrow m$, $\mathrm{smap}_f = f{+}1$: do $f$ on the old cells and send the new cell $n$ to the new cell $m$.

$\iota : n \hookrightarrow n{+}1$ is the inclusion. One name, of type $\Lc$, whose value is the new cell $n$.

$R_{\fresh} X(n) = X(n{+}1)$.

Guarded: $\tick$

$\Pos(0) = \varnothing$: with no steps left the lock cannot be crossed. $\Pos(n{+}1) = \{\ast\}$ and $\sc(n{+}1) = n$.

$\iota : n{+}1 \to n$ is the unique map. No names.

$R_{\tick} X(0) = 1$ (an empty product) and $R_{\tick} X(n{+}1) = X(n)$: the later modality $\triangleright$.

Several positions: Staton's binder over $\Inj$ (illustration only, not in the development)

What would Staton's exponential binder look like as a lock kind over $\Inj$? Since $y\,n \times \Const_{\Lc} \cong y(n{+}1) + n \cdot y\,n$, the exponential is $X^{\Const_{\Lc}}(n) = X(n{+}1) \times \prod_{i \in \Fin n} X(n)$. That is the lock kind with $$\Pos(n) = 1 + \Fin\,n, \qquad \sc(n, \mathsf{new}) = n{+}1, \qquad \sc(n, i) = n.$$ The bound cell is either new, or equal to existing cell $i$, and something behind this lock must handle every case. The case split Staton expresses with $?_=$ sits inside the positions.

II.4 Lock words, and the signature polynomial

A lock word $\mu = \kappa_1 \cdots \kappa_k$ (I.4) is crossed one lock at a time, so a way of crossing it is a sequence of choices. The first choice changes the world, and the second is made at the new world:

Positions and scope of a lock word
$$\WPos\,\varepsilon\,w = \{\ast\} \qquad \WPos\,(\kappa\mu)\,w = \sum_{p \in \Pos_\kappa(w)} \WPos\,\mu\,\big(\sc_\kappa(w,p)\big)$$ $$\wsc\,\varepsilon\,w\,\ast = w \qquad \wsc\,(\kappa\mu)\,w\,(p, \vec p) = \wsc\,\mu\,\big(\sc_\kappa(w,p)\big)\,\vec p$$

This is again an arity, the composite of the lock kinds' arities. In the code it is wordE μ, built with the composite E κ ⊙ wordE μ.

Local state

$\WPos\,\fresh\fresh\,n = \{\ast\}$ and $\wsc = n{+}2$: allocate two cells.

Guarded

$\WPos\,\tick\tick\,1 = \varnothing$: one step left, two ticks cannot be crossed.

Now the whole operation signature becomes one polynomial. A shape is an operation together with its parameters, and a position is a slot together with a way of crossing that slot's lock word:

The signature polynomial
$$\Ext\,X(w) \;=\; \sum_{o} \ \sum_{\vec c \in \Par_o(w)} \ \prod_{a \in \Ar\,o} \ \prod_{\vec p \in \WPos(\slot\,o\,a)(w)} X\big(\wsc(\slot\,o\,a)(w, \vec p)\big)$$
  • Shapes $\Ext\,1(w) = \sum_o \Par_o(w)$.
  • Arity of shape $(o, \vec c)$: $\sum_{a \in \Ar\,o} \sum_{\vec p} y\big(\wsc(\slot\,o\,a)(w, \vec p)\big)$.

An element of $\Ext\,X$ at $w$ is one layer of a program: an operation, its parameter values, and one $X$ per continuation, each at the world its lock word leads to.

Part III

Parametric right adjoints

The universal property of the polynomials of Part II, and how it turns into typing rules.

III.1 The definition

A functor $R$ is a right adjoint if there is a functor $L$ with $\mathcal B(\Gamma, R X) \cong \mathcal A(L\Gamma, X)$, naturally: maps into $R X$ are the same as maps out of $L\Gamma$. Right adjoints are the best-behaved functors, but they must preserve the terminal object, $R\,1 \cong 1$. $\Maybe$, $\List$ and $\Ext$ do not: their value on $1$ is their set of shapes, which has more than one element. The fix is to keep track of shapes.

Definition (Weber; nLab)

Let $\mathcal A$ have a terminal object $1$, and let $T : \mathcal A \to \mathcal B$. Every $T X$ comes with a map $T(!) : T X \to T\,1$, which sends each element to its shape. So $T$ factors canonically: $$\mathcal A \xrightarrow{\ T_1\ } \mathcal B / T1 \xrightarrow{\ \Sigma_{T1}\ } \mathcal B, \qquad T_1 X = (T X,\ T(!)).$$ Here $\mathcal B/T1$ is the slice category: objects are $\Gamma$ together with a map $\Gamma \to T1$ (every element labelled by a shape), and maps preserve the labels. $\Sigma_{T1}$ forgets the label. $T$ is a parametric right adjoint (PRA) if $T_1$ is a right adjoint.

Unfolding the definition: a map $\Gamma \to T X$ is a shape $s : \Gamma \to T1$ together with contents, a map $L(\Gamma, s) \to X$ out of the left adjoint $L$ of $T_1$. On a single point labelled $s$, the left adjoint gives the arity of $s$. For $T X = \sum_s X^{P(s)}$ on sets, $L(\{\ast\}, s) = P(s)$: a single element of shape $s$ unpacks to its set of positions. If $T1 = 1$ there is only one shape, $\mathcal B/1 \cong \mathcal B$, and a PRA is exactly a right adjoint.

III.2 On presheaves, PRAs are exactly the polynomials

There are two directions to check.

Every polynomial is a PRA

Take $T X(w) = \sum_{s} \Psh(E(w,s), X)$ as in II.2. A map from a point $y\,w$ into $T X$ is, by Yoneda, an element of $T X(w)$, i.e. a shape $s$ together with a map $E(w,s) \to X$. Fixing the shape, the maps into $T X$ are the maps out of $E(w,s)$. That is the PRA property at representables, with left adjoint $L(y\,w, s) = E(w,s)$. Every presheaf is a colimit of representables, so this extends to all of $\Psh/T1$.

Every PRA is a polynomial: generic elements

Conversely, let $T$ be a PRA and take a shape $s \in T1(w)$. Set $A = L(y\,w, s)$, the arity, and let $g \in T(A)(w)$ be the unit of the adjunction at $(y\,w, s)$. This $g$ is the generic element of shape $s$: the element whose contents are "each position holds its own name". Every element of $T X(w)$ of shape $s$ is obtained from $g$ by renaming its contents along exactly one map $A \to X$. That is the generic factorization.

Theorem (Weber, Prop. 2.10 and Rem. 2.12, as cited on nLab; nLab Prop. 3.3)

For a functor $T$ between presheaf categories, the following are equivalent:

  1. $T$ is a PRA;
  2. every element of $T1$ at a representable has a generic factorization;
  3. $T$ is a polynomial in $\mathbf{Cat}$, with arities $E(w,s) = L(y\,w, s)$.

One refinement. A general PRA may have any presheaf as an arity. The polynomials of Part II have arities that are sums of representables, the $\Fam(\W)$-valued ones, sometimes called familial. That restriction is what lets "behind a lock, at a position" be a world, which Part IV relies on.

In our setting

  • Each modality $R_\kappa$ is a one-shape PRA, i.e. an honest right adjoint. Its left adjoint is called the lock, $L_\kappa$ (III.3).
  • The signature functor $\Ext$ is a many-shape PRA with shapes $\Ext\,1 = \sum_o \Par_o$. The shapes depend on the world.
A generic element in local state

Take the shape (lookup, cell $i$) at world $n$. Its arity is $y\,n + y\,n$, two points at world $n$. The generic element is "read cell $i$ and continue in the first point or in the second point". Any concrete $\mathsf{read}_i(x, y)$ is this generic element with the first point renamed to $x$ and the second to $y$.

"Polynomial" here means a polynomial in $\mathbf{Cat}$, not an internal polynomial built from $\Sigma$, $\Pi$ and pullback inside the presheaf topos. $R_{\fresh}$ is not of the internal form: it would have to be an exponential $X^A$, forcing $y\,n \times A \cong y(n{+}1)$, and at $n = 0$ that forces $A = y\,1$, but $y\,1 \times y\,1 \not\cong y\,2$. The same argument rules out $\triangleright$.

III.3 The lock $L_\kappa$, concretely

Since $R_\kappa$ is a right adjoint, it has a left adjoint $L_\kappa$. That left adjoint is what a lock in a context will mean. It is determined by what it does to single points, and that is the arity:

Familial representability
$$L_\kappa(y\,w) \;\cong\; E_\kappa(w) \;=\; \sum_{p \in \Pos_\kappa(w)} y\big(\sc_\kappa(w,p)\big)$$

Behind a $\kappa$-lock placed right after a single point at world $w$, you are at one of the worlds $\sc_\kappa(w,p)$, one for each way of crossing.

On a general presheaf $\Gamma$, which is glued from points, $L_\kappa$ glues the corresponding arities. Explicitly, as a quotient (a coend):

The lock on an arbitrary presheaf
$$L_\kappa \Gamma(t) = \Big(\sum_{v} \sum_{q \in \Pos_\kappa(v)} \Gamma(v) \times \W\big[\sc_\kappa(v,q), t\big]\Big) \Big/ \sim$$

An element of $L_\kappa\Gamma$ at world $t$ is a triple:

  • an element $e$ of $\Gamma$ at some earlier world $v$;
  • a way $q$ of crossing the lock at $v$;
  • a way of continuing from the far side $\sc_\kappa(v,q)$ on to $t$.

The relation $\sim$ identifies "move $e$ forward, then cross" with "cross, then move forward".

The adjunction is two transposes. A map $\psi : L_\kappa\Gamma \to X$ goes to $e \mapsto (q \mapsto \psi\langle v, q, e, \mathrm{id}\rangle)$, a map $\Gamma \to R_\kappa X$. In the other direction, $\varphi : \Gamma \to R_\kappa X$ goes to $\langle v, q, e, g\rangle \mapsto X(g)(\varphi(e)(q))$.

Local state

$L(y\,n) \cong y(n{+}1)$: behind an allocation at $n$ cells, you are at $n{+}1$ cells.

Applied to the presheaf of cells: $L(\Const_{\Lc}) \cong y\,2$. An element is a cell plus a new cell distinct from it, i.e. a pair of distinct cells.

In general $L\Gamma$ is "$\Gamma$ together with one cell that $\Gamma$ does not mention" (nominal sets call this the separated product $\Gamma * \Lc$).

Guarded

$L(y(n{+}1)) \cong y\,n$ and $L(y\,0) = 0$: nothing lives behind a tick at stage 0.

In general $(L\Gamma)(n) = \Gamma(n{+}1)$: behind the lock at stage $n$ you hold an environment from one step earlier. This is "earlier", $\triangleleft$.

Summands

Say a presheaf $\Gamma$ lies over the world $w$ if it comes with a map $\pi : \Gamma \to y\,w$. Then each element of $\Gamma$ at $t$ carries a way that $t$ is a future of $w$. Applying the lock to $\pi$ gives $L_\kappa\Gamma \to L_\kappa(y\,w) \cong \sum_p y(\sc_\kappa(w,p))$. So every element of $L_\kappa\Gamma$ also carries a position $p$, the way it crossed. Grouping elements by $p$ splits $L_\kappa\Gamma$ into summands, one per position, and the $p$-th summand lies over the single world $\sc_\kappa(w,p)$.

This is the semantic fact behind the shape of PRACBPV's contexts (IV.3): if you start over one world and record which way you crossed, you are again over one world.

III.4 Why PRAs become typing rules

A term $\Gamma \vdash t : A$ denotes a map $\den\Gamma \to \den A$. So a universal property of the form "maps into this ≅ maps out of that" is a ready-made introduction rule, provided "that" is something a context can express.

From a right adjoint: Fitch-style modal rules

Because $\Psh(L\Gamma, X) \cong \Psh(\Gamma, R X)$, add a context former, a lock $\Gamma, 🔒$ meaning $L\Gamma$, and a type $[R]A$ meaning $R\den A$:

$$\frac{\Gamma, 🔒 \vdash t : A}{\Gamma \vdash \shut\, t : [R]A} \qquad \frac{\Gamma \vdash t : [R]A}{\Gamma, 🔒 \vdash \opn\, t : A}$$

$\shut$ is the bijection used forwards, and $\opn$ is the counit $L R \to \mathrm{id}$. The equations $\opn(\shut\,t) = t$ and $\shut(\opn\,t) = t$ are its two round trips. This style of rule is called Fitch-style (Clouston; Birkedal et al.).

From a many-shape PRA: the operation rule

A map $\Gamma \to \Ext\,X$ is a shape chosen from $\Gamma$ (an operation and its parameters) together with contents in the context $L(\Gamma, \text{shape})$: one term behind each slot's lock word, at each of its positions. Part IV turns exactly this into the operation rule.

And for substitution (Gratzer, Cavallo, Kavvos, Guatto, Birkedal 2022)

Pushing a substitution through $\opn$ requires that the lock functor $\Gamma \mapsto \Gamma, 🔒$ on contexts is itself a PRA. Its shapes are called keys: a key is a substitution $r : \Delta \to 1, 🔒$. In the pure syntax, a key amounts to picking out one lock of $\Delta$. The PRA property says a substitution $\Delta \to \Gamma, 🔒$ is the same as a key $r$ together with a substitution $\Delta/r \to \Gamma$, where $\Delta/r$ is "$\Delta$ cut off at that lock". The interlude shows why this is needed.

Interlude Fitch-style STLC: the binder fragment alone

Before assembling PRACBPV, it helps to see locks without operations. Take the simply typed λ-calculus (STLC) and add one modality $[R]$ and one lock $🔒$, with the two rules of III.4 plus two more:

$$\frac{\Gamma \vdash t : A}{\Gamma, 🔒 \vdash \up\,t : A} \qquad \frac{}{\Gamma, 🔒 \vdash \nm : N}$$
  • $\up$ uses something from before the lock behind it. Semantically it needs a map $\mathsf{wk} : L\Gamma \to \Gamma$, "crossing the lock forgets nothing you need". This is the strength of II.3.
  • $\nm$ is the thing the lock creates, of some type $N$. Semantically it is a global element of $R\,N$, the names of II.3.

Three models make the rules concrete. The first two are the running examples. The third uses cubical sets: presheaves on the category of cubes, where world $n$ means "$n$ dimensions", together with the interval $\I$ of coordinates.

The lesson for substitution. Suppose $\opn$, $\up$ and $\nm$ only apply when the lock is the last thing in the context. Then $\Gamma, 🔒, x{:}B \vdash \opn\,t$ is not derivable. That second half is the PRA decomposition of the lock from III.4.

IV.2 Types

As in CBPV, there are value types $A$ (things a program can hold) and computation types $B$ (things a program can do). $U B$ is the type of suspended computations (thunks), and $F A$ is the type of computations that return an $A$.

$$A ::= \mathbb 1 \mid A \times A \mid U B \mid \mathsf{base}\ b \mid [\kappa] A \qquad\qquad B ::= F A \mid A \Rightarrow B$$

The two new value types: $\mathsf{base}\ b$ is a type of parameters, and $[\kappa]A$, "an $A$ on the far side of a $\kappa$-lock", is the modality of II.3. There is one modality per lock kind. Operations get no type former; they appear only through the operation rule (IV.5).

Local state

$[\fresh]A$: an $A$ that may mention one newly allocated cell. (Elsewhere written $\Lc \multimap A$.)

Guarded

$[\tick]A = \triangleright A$: an $A$ one step later.

IV.3 Contexts are telescopes over a world

A context records the variables in scope, and also the locks crossed so far and the world they lead to. Because later entries depend on earlier ones (a position is only meaningful at the world reached so far), contexts are telescopes, defined together with the function computing their world.

Definition (Syntax.agda, Tele and world)
$$\Theta ::= \varnothing_w \;\mid\; \Theta, A \;\mid\; \Theta \lockat{p}{\kappa} \quad \text{where } p \in \Pos_\kappa(\wd\,\Theta)$$ $$\wd(\varnothing_w) = w \qquad \wd(\Theta, A) = \wd\,\Theta \qquad \wd(\Theta \lockat{p}{\kappa}) = \sc_\kappa(\wd\,\Theta, p)$$

For a lock word $\mu$ and $\vec p \in \WPos\,\mu\,(\wd\,\Theta)$, write $\Theta \lockat{\vec p}{\mu}$ for its locks appended one at a time. Its world is $\wsc\,\mu\,(\wd\,\Theta)\,\vec p$.

The three formers:

  • $\varnothing_w$: the root, "at world $w$, no variables". It denotes the representable $y\,w$, a single point at $w$.
  • $\Theta, A$: add a variable of type $A$. The world does not change.
  • $\Theta \lockat{p}{\kappa}$: cross a $\kappa$-lock in way $p$. The world becomes the scope. It denotes the $p$-th summand of $L_\kappa\den\Theta$ (III.3).

Every telescope therefore lies over exactly one world, $\wd\,\Theta$. That is what lets the operation rule ask for parameters "at the current world" and positions "at the current world".

Local state

$\varnothing_0,\ u{:}\mathbb 1 \lockat{}{\fresh},\ x{:}\Lc$ has world 1: $u$ was bound with no cells, then one cell was allocated, then $x$ was bound. Since $\Pos_{\fresh} = \{\ast\}$, the position is usually not written.

Guarded

$\varnothing_2 \lockat{}{\tick} \lockat{}{\tick}$ has world 0. A third tick cannot be written, because $\Pos_{\tick}(0) = \varnothing$ offers no position to put in it.

So PRACBPV departs from the Fitch-style literature in two places, both deliberate.

  1. The root is a world, not the empty context. This is the POPL paper's $w \mid \Gamma$ extended with locks, and it is what the operational semantics needs: programs run at a world. With no lock kinds, a telescope is exactly $\varnothing_w, A_1, \ldots, A_n$, i.e. $w \mid \Gamma$.
  2. A lock records a position, and denotes a summand. Over a single world, $L_\kappa$ lands in a sum over positions (III.3). The syntax splits that sum as soon as the lock is written, so contexts stay over one world. In the Fitch-style calculi, $\Gamma, 🔒$ is the whole of $L\Gamma$, and the choice among positions is never made in the context.

In both instances the second difference is almost invisible. With one position, the single summand is all of $L_\kappa\Theta$. With no positions, which only happens for $\tick$ at stage 0, the summand is empty, so instead of a formable but empty context $\Gamma, 🔒$ there is no context at all. The difference would matter for a lock kind with several positions, like the one at the end of II.3.

The payoff of both choices is the closing isomorphism, familial representability read in the syntax:

$$\den{\varnothing_u \lockat{p}{\kappa}} \;\cong\; \den{\varnothing_{\sc_\kappa(u,p)}}$$

A lock right after the root is just a later root. The machine uses this after every operation (IV.6).

IV.6 Renamings, substitutions, and closing

Renamings and substitutions are inductive data, each constructor being one structure map. The lock-related ones:

  • keepL: rename under a lock of the same kind. This is $L_\kappa$ acting on maps; positions are pulled back along the renaming's world map.
  • dropL: rename into a context with one more lock, using the strength.
  • lockₛ σ p τ: a substitution out of a locked telescope goes through a lock of the target, then a renaming. This is the PRA decomposition of the lock from III.4, and it is how a substitution is pushed past $\opn$.
  • close p f: the closing isomorphism of IV.3. A lock right after the root is a later root, and its names become constants.

The operational semantics runs closed programs at a world. When it runs $\mathsf{new}$ at world $n$, the continuation lives in $\varnothing_n \lockat{}{\fresh}$. close turns it into a closed program at world $n{+}1$, replacing $\nm_0$ by $\mathsf{const}\ n$. Running $\mathsf{step}$ at stage $n{+}1$ is the same with $\tick$ and stage $n$.

The denotational semantics

Every piece of syntax, interpreted with the structure it came from.

V.1 Algebras, and the types

Algebras of the signature

An $\Ext$-algebra is a presheaf $C$ together with a map $\Ext\,C \to C$. It says how to perform any operation, given its parameters and one element of $C$ per continuation at the right world. The free $\Ext$-algebra on a presheaf $X$ is the presheaf of trees of operations with leaves in $X$: programs that may perform operations and finally return an $X$. Its algebra structure just adds a node.

V.4 The operation rule

$$\den{\op\ o\ \vec V\ k} \;=\; \den\Theta \xrightarrow{\ \text{opNode}\ } \Ext\,\den B \xrightarrow{\ \text{algebra of } \den B\ } \den B$$
  1. shutW: each continuation, "a term behind the word, for each position", is transposed through its lock word into a map $\den\Theta \to R_{\slot\,o\,a}\den B$, i.e. a $B$ at every world the word can lead to. This is $\shut$ iterated along the word.
  2. opNode: pair the shape $(o, \den{\vec V})$ with the transposed continuations. The result is an element of $\Ext\,\den B$, read off directly from the PRA structure (III.4).
  3. The algebra of $\den B$ performs the operation.

For the empty lock word, step 1 does nothing, and this is the POPL paper's interpretation of operations.

Local state

$\den{\mathsf{newℓ}\ b\ M}$: transpose $\den M : L_{\fresh}\den\Theta \to \den B$ into $\den\Theta \to R_{\fresh}\den B$, a $B$ at world $n{+}1$. Pair it with the shape $\mathsf{new}_b$, then apply $\den B$'s algebra.

Guarded

$\den{\mathsf{delay}\ M}$ at stage $n{+}1$: the transposed continuation is a $B$ at stage $n$. At stage 0 the product over positions is empty, so the operation node has no continuation at all.
