# One-Frame Operational Semantics for CBPV

Tree reduction moves operations out one frame at a time and is strongly normalizing. Configuration reduction terminates by a multiset metric whenever the monadic container is affine, meaning no neighbor of the hole is copied. No postulates. Each table row links to the Agda definition.

Notation: `_⇝_` is the head step `↦red`, `_↦_` is tree reduction, `_↦T_` is configuration reduction, and `𝒞⟦ B ⟧` is the relation `𝒞[B]`.
