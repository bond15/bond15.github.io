1. Contextual equivalence

Definition (closed Boolean equivalence). For \(\vdash e : \mathsf{bool}\) and \(\vdash e' : \mathsf{bool}\):

\[ e \equiv^{\mathsf{cl}}_{\mathsf{bool}} e' \quad:=\quad (e \longrightarrow^* \mathsf{true} \text{ and } e' \longrightarrow^* \mathsf{true}) \text{ or } (e \longrightarrow^* \mathsf{false} \text{ and } e' \longrightarrow^* \mathsf{false}) \]

Example. \(\mathsf{true} \equiv^{\mathsf{cl}}_{\mathsf{bool}} (\lambda x{:}\mathsf{int}.\, \mathsf{true})\, 5\): the left is \(\mathsf{true}\), the right steps to \(\mathsf{true}\) by β.

The definition and the example.

Definition (context). A term with one hole, anywhere:

\[ \begin{aligned} C ::= {} & [\,] \mid \lambda x{:}\tau.\, C \mid C\, e \mid e\, C \mid C + e \mid e + C \\ & \mid \mathsf{if}\ C\ \mathsf{then}\ e_1\ \mathsf{else}\ e_2 \mid \mathsf{if}\ e\ \mathsf{then}\ C\ \mathsf{else}\ e_2 \mid \mathsf{if}\ e\ \mathsf{then}\ e_1\ \mathsf{else}\ C \end{aligned} \]

\(C[e]\) puts \(e\) in the hole, without renaming. Unlike an evaluation context: the hole may sit under a λ, and the other positions hold any \(e\), not only values.

Example (capture). \((\lambda x{:}\mathsf{int}.\, [\,])[x] = \lambda x{:}\mathsf{int}.\, x\). The free \(x\) is bound by the context.

Definition (typed context). \(C : (\Gamma \vdash \tau) \Rightarrow (\Gamma' \vdash \tau')\) when for every \(e\), \(\Gamma \vdash e : \tau\) implies \(\Gamma' \vdash C[e] : \tau'\).

Contexts, plugging, the capture example, typed contexts.

Definition (contextual equivalence). For \(\Gamma \vdash e : \tau\) and \(\Gamma \vdash e' : \tau\):

\[ e \equiv^{\mathsf{ctx}}_{\Gamma \vdash \tau} e' \quad:=\quad \forall C : (\Gamma \vdash \tau) \Rightarrow (\cdot \vdash \mathsf{bool}).\ \ C[e] \equiv^{\mathsf{cl}}_{\mathsf{bool}} C[e'] \]

Also called observational equivalence. Closed \(\mathsf{bool}\) is the observation; with effects, closing at \(1\) is also used.

The definition.

2. Congruence and adequacy

Lemma (congruence). If \(C : (\Gamma \vdash \tau) \Rightarrow (\Gamma' \vdash \tau')\) and \(e \equiv^{\mathsf{ctx}}_{\Gamma \vdash \tau} e'\) then \(C[e] \equiv^{\mathsf{ctx}}_{\Gamma' \vdash \tau'} C[e']\). Proof: given \(C' : (\Gamma' \vdash \tau') \Rightarrow (\cdot \vdash \mathsf{bool})\), the context \(C'[C[\,]]\) is \((\Gamma \vdash \tau) \Rightarrow (\cdot \vdash \mathsf{bool})\), and \(C'[C[e]] = (C'[C[\,]])[e]\).

Lemma (adequacy). If \(e \equiv^{\mathsf{ctx}}_{\cdot \vdash \mathsf{bool}} e'\) then \(e \equiv^{\mathsf{cl}}_{\mathsf{bool}} e'\). Proof: take \(C = [\,]\).

Example. \(\lambda y{:}\mathsf{int}.\, \mathsf{true} \equiv^{\mathsf{ctx}}_{\cdot \vdash \mathsf{int} \to \mathsf{bool}} \lambda y{:}\mathsf{int}.\, (\lambda x{:}\mathsf{int}.\, \mathsf{true})\, 5\). No step applies: no reduction under λ. By congruence with \(C = \lambda y{:}\mathsf{int}.\, [\,]\), it suffices that \(\mathsf{true} \equiv^{\mathsf{ctx}}_{y:\mathsf{int} \vdash \mathsf{bool}} (\lambda x{:}\mathsf{int}.\, \mathsf{true})\, 5\), which section 3 gives.

Theorem (greatest adequate congruence). If \(R\) is a family of relations on well-typed terms that is adequate (\(e\, R\, e'\) at \(\cdot \vdash \mathsf{bool}\) implies \(e \equiv^{\mathsf{cl}}_{\mathsf{bool}} e'\)) and a congruence (closed under every typed context), then \(e\, R\, e'\) implies \(e \equiv^{\mathsf{ctx}} e'\). Proof: for \(C : (\Gamma \vdash \tau) \Rightarrow (\cdot \vdash \mathsf{bool})\), \(C[e]\, R\, C[e']\) by congruence, so \(C[e] \equiv^{\mathsf{cl}}_{\mathsf{bool}} C[e']\) by adequacy. This is how every contextual equivalence is proved: never from the definition.

Composition of contexts, \((C \circ C')[e] = C[C'[e]]\); then congruence and adequacy.

3. Denotational equivalence

Definition. For \(\Gamma \vdash e : \tau\) and \(\Gamma \vdash e' : \tau\), with \([\![e]\!] : [\![\Gamma]\!] \to [\![\tau]\!]\) from Discussion 8: \(e \equiv^{\mathsf{den}}_{\Gamma \vdash \tau} e' := [\![e]\!] = [\![e']\!]\).

Lemma (compositionality for contexts). For \(C : (\Gamma \vdash \tau) \Rightarrow (\Gamma' \vdash \tau')\) there is \([\![C]\!] : ([\![\Gamma]\!] \to [\![\tau]\!]) \to ([\![\Gamma']\!] \to [\![\tau']\!])\) with \([\![C[e]]\!] = [\![C]\!]\,[\![e]\!]\). By induction on \(C\); the λ case is \([\![\lambda x{:}\tau_1.\, C]\!]\,g = \gamma \mapsto z \mapsto [\![C]\!]\,g\,(\gamma, x \mapsto z)\).

Theorem. \(\equiv^{\mathsf{den}}\) is an adequate congruence, so \(e \equiv^{\mathsf{den}} e'\) implies \(e \equiv^{\mathsf{ctx}} e'\). Congruence: \([\![e]\!] = [\![e']\!]\) gives \([\![C]\!]\,[\![e]\!] = [\![C]\!]\,[\![e']\!]\). Adequacy: at \(\cdot \vdash \mathsf{bool}\), \(e \longrightarrow^* [\![e]\!](*) = [\![e']\!](*)\) and \(e' \longrightarrow^* [\![e']\!](*)\), by adequacy from Discussion 8.

Example. \([\![\mathsf{true}]\!](*) = \mathsf{true}\) and \([\![(\lambda x{:}\mathsf{int}.\, \mathsf{true})\, 5]\!](*) = (z \mapsto \mathsf{true})(5) = \mathsf{true}\). So \(\mathsf{true} \equiv^{\mathsf{ctx}}_{\cdot \vdash \mathsf{bool}} (\lambda x{:}\mathsf{int}.\, \mathsf{true})\, 5\), and likewise under \(y{:}\mathsf{int}\), where both meanings are \(\gamma \mapsto \mathsf{true}\).

Corollary. If \(e \longrightarrow^* e'\) then \(e \equiv^{\mathsf{ctx}} e'\): by soundness, \([\![e]\!] = [\![e']\!]\).

Theorem (completeness, pure STLC). With only \(\to\), \(\times\), \(+\), \(1\), \(0\) and \(\mathsf{bool}\), \(e \equiv^{\mathsf{ctx}} e'\) implies \(e \equiv^{\mathsf{den}} e'\): every \([\![\tau]\!]\) is finite and every element is the meaning of a term. Fails with \(\mathbb{N}\) and recursion: \([\![\mathsf{nat} \to \mathsf{nat}]\!]\) contains functions no term names and no context separates.

Both meanings in Rocq, equal by computation.

4. Axiomatic equivalence

Definition. \(\Gamma \vdash e \equiv^{\mathsf{ax}} e' : \tau\) is the least relation closed under: reflexivity, symmetry, transitivity; one congruence rule per constructor (\(e_1 \equiv^{\mathsf{ax}} e_1'\) and \(e_2 \equiv^{\mathsf{ax}} e_2'\) give \(e_1\, e_2 \equiv^{\mathsf{ax}} e_1'\, e_2'\), and so on); and for each type a β law and an η law, below.

  • β: an introduction form inside an elimination form simplifies. Computation.
  • η: a term of the type equals the introduction form built from its eliminations. Reasoning; no step rule looks like it.

Definition (functions). Intro \(\lambda x{:}\tau.\, e\), elim \(e\, e'\).

\[ \begin{gathered} (\lambda x{:}\tau.\, e)\, e' \equiv^{\mathsf{ax}} e[x \mapsto e'] \ (\beta) \qquad e \equiv^{\mathsf{ax}} \lambda x{:}\tau_1.\, e\, x \ (\eta) \\[.4em] \frac{\Gamma, x{:}\tau_1 \vdash e\, x \equiv^{\mathsf{ax}} e'\, x : \tau_2}{\Gamma \vdash e \equiv^{\mathsf{ax}} e' : \tau_1 \to \tau_2} \ (\eta') \end{gathered} \]

β is the step rule on open terms with any argument \(e'\), not only a value. η′ (extensionality) follows from η and congruence.

Definition (products). Intro \((e_1, e_2)\), elim \(e.1\), \(e.2\).

\[ \begin{gathered} (e_1, e_2).1 \equiv^{\mathsf{ax}} e_1 \qquad (e_1, e_2).2 \equiv^{\mathsf{ax}} e_2 \ (\beta) \qquad e \equiv^{\mathsf{ax}} (e.1, e.2) \ (\eta) \\[.4em] \frac{e.1 \equiv^{\mathsf{ax}} e'.1 \quad e.2 \equiv^{\mathsf{ax}} e'.2}{e \equiv^{\mathsf{ax}} e'} \ (\eta') \end{gathered} \]

Definition (unit). Intro \(()\), no elim. No β. \(e \equiv^{\mathsf{ax}} () \ (\eta)\); equivalently \(e \equiv^{\mathsf{ax}} e'\) for any two terms of type \(1\).

Definition (sums). Intro \(\mathsf{inl}\ e\), \(\mathsf{inr}\ e\); elim \(\mathsf{case}\ e\ \{\mathsf{inl}\ x_1 \to e_1 \mid \mathsf{inr}\ x_2 \to e_2\}\).

\[ \begin{gathered} \mathsf{case}\ (\mathsf{inl}\ e)\ \{\mathsf{inl}\ x_1 \to e_1 \mid \mathsf{inr}\ x_2 \to e_2\} \equiv^{\mathsf{ax}} e_1[x_1 \mapsto e] \ (\beta) \\ \mathsf{case}\ (\mathsf{inr}\ e)\ \{\mathsf{inl}\ x_1 \to e_1 \mid \mathsf{inr}\ x_2 \to e_2\} \equiv^{\mathsf{ax}} e_2[x_2 \mapsto e] \ (\beta) \end{gathered} \]
\[ e \equiv^{\mathsf{ax}} \mathsf{case}\ e\ \{\mathsf{inl}\ x_1 \to \mathsf{inl}\ x_1 \mid \mathsf{inr}\ x_2 \to \mathsf{inr}\ x_2\} \ (\text{weak } \eta) \]
\[ \begin{gathered} \Gamma \vdash e' : \tau_1 + \tau_2 \qquad \Gamma, x{:}\tau_1 + \tau_2 \vdash e : \tau \\ \Gamma \vdash e[x \mapsto e'] \equiv^{\mathsf{ax}} \mathsf{case}\ e'\ \{\mathsf{inl}\ x_1 \to e[x \mapsto \mathsf{inl}\ x_1] \mid \mathsf{inr}\ x_2 \to e[x \mapsto \mathsf{inr}\ x_2]\} : \tau \ (\text{strong } \eta) \end{gathered} \]

Strong η is the second line, under the two typing premises on the first. Weak η is strong η at \(e = x\). Strong η is weak η plus the commuting conversions. The side condition keeps \(e'\) from mentioning anything bound inside \(e\).

Definition (zero). No intro; elim \(\mathsf{case}\ e\ \{\}\). No β. Weak η: \(e \equiv^{\mathsf{ax}} \mathsf{case}\ e\ \{\}\) for \(e : 0\). Strong η: for \(\Gamma \vdash e' : 0\) and \(\Gamma, x{:}0 \vdash e : \tau\), \(e[x \mapsto e'] \equiv^{\mathsf{ax}} \mathsf{case}\ e'\ \{\}\).

Example (commuting conversion). \(\mathsf{bool} = 1 + 1\), \(\mathsf{if}\) is its \(\mathsf{case}\). Strong η with \(e' = b\):

\[ e[x \mapsto \mathsf{if}\ b\ \mathsf{then}\ e_2\ \mathsf{else}\ e_3] \equiv^{\mathsf{ax}} \mathsf{if}\ b\ \mathsf{then}\ e[x \mapsto e_2]\ \mathsf{else}\ e[x \mapsto e_3] \]

In each branch the value of \(x\) is known, so each branch simplifies further.

Example (dead code). With \(f{:}1 \to 0\) in \(\Gamma\) and any \(\Gamma \vdash e : \tau\): \(e = e[x \mapsto f\,()]\) for a fresh \(x\), so \(e \equiv^{\mathsf{ax}} \mathsf{case}\ (f\,())\ \{\}\). Every term under a hypothesis of type \(0\) equals the empty case, whether or not it uses the hypothesis.

5. The laws in the model

Lemma. Every β and η law holds in the model of Discussion 7: a type is a Rocq type, a term with a free variable \(x\) is a Rocq function of \(x\), \(e[x \mapsto e']\) is application. Each proof is reflexivity (β, η for functions) or destruct on the value (η for products, unit, sums, zero). η′ for functions is assumed (funext).

Three types for the laws to range over.

Functions: β, η, η′.

Products: β, η, η′.

Unit: η, both forms.

Sums: β, weak η, strong η; the commuting conversion for \(\mathsf{if}\).

Zero: strong η; dead code.

Remark (polarity). Functions, products, unit: negative, used by application and projection, η says the term is the intro form of its eliminations. Sums, zero: positive, used by pattern matching, η says a term using them may match first. One η pattern per polarity.

Theorem (soundness). \(e \equiv^{\mathsf{ax}} e'\) implies \(e \equiv^{\mathsf{den}} e'\) implies \(e \equiv^{\mathsf{ctx}} e'\). The first by the lemma above and induction on the derivation; the second by section 3.

Theorem (completeness, pure STLC). \(e \equiv^{\mathsf{ctx}} e'\) implies \(e \equiv^{\mathsf{ax}} e'\). Fails with \(\mathbb{N}\) and primitive recursion: \(\equiv^{\mathsf{ax}}\) is recursively enumerable and \(\equiv^{\mathsf{ctx}}\) is not. Deciding \(\equiv^{\mathsf{ax}}\) includes deciding whether \(0\) is inhabited under \(\Gamma\) (dead code): decidable here, undecidable with dependent types.

The first example in the model. Print Assumptions: strong η for sums uses no axiom.
