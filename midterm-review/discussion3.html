Where induction principles come from

Read the shape of an inductive definition, predict the induction principle, and then use the same idea to define small-step semantics.

1. One constructor, one proof case

For every inductive type T, Rocq generates T_ind. To prove (P(t)) for every (t:T), provide one case for every constructor. Every recursive constructor argument contributes an induction hypothesis.

Enumeration: induction is case analysis

\[ \frac{P(A) \qquad P(B) \qquad P(C)}{\forall x.\,P(x)} \]

MyType has three constructors and none is recursive, so there are three cases and no induction hypotheses. The first property is deliberately trivial; the second states that every value is (A), (B), or (C).

Naturals: the first induction hypothesis

\[ \frac{P(\mathsf{zero}) \qquad \forall n.\,P(n) \Rightarrow P(\mathsf{succ}\ n)}{\forall n.\,P(n)} \]

The succ constructor contains one recursive nat, so its proof case receives one induction hypothesis. That is exactly what the proof of plus n zero = n rewrites with.

Binary trees: one hypothesis per subtree

\[ \frac{P(\mathsf{leaf}) \qquad \forall x\,l\,r.\,P(l)\Rightarrow P(r)\Rightarrow P(\mathsf{node}\ x\ l\ r)}{\forall t.\,P(t)} \]

A node has two recursive arguments. The proof that mirroring twice returns the original tree therefore gets one hypothesis for the left subtree and one for the right.

Syntax trees: structural induction is ordinary induction

The example counts variable occurrences and proves that every untyped lambda term contains at least one variable occurrence. Its proof has exactly the shape predicted by utlc_ind.

2. Inference rules become constructors

A small-step relation is another inductive definition. Each inference rule becomes a constructor; a derivation tree becomes a Rocq proof; and a multi-step execution is the reflexive-transitive closure of the one-step relation.

Boolean warm-up

Use Booleans to establish the pattern: encode the syntax, turn each reduction rule into a constructor of step, prove one step, then chain steps with multi.

\[\frac{b_0\to b_2}{b_0\lor b_1\to b_2\lor b_1}\]
\[\frac{}{\mathsf{true}\lor b_1\to\mathsf{true}}\]
\[\frac{}{\mathsf{false}\lor b_1\to b_1}\]

Mini-IMP: the configuration carries a store

For commands, a term alone is not enough. A configuration ⟨(c,\sigma)⟩ pairs a command with a state. Assignment changes the state; variables read from it; sequencing and while determine which command comes next.

Worked route

Define Boolean expressions and commands, add the store, encode the step rules, and execute X := true; while X do X := false through its configurations.

3. Call-by-value lambda calculus

The same recipe now encodes call-by-value lambda calculus: define values, define capture-avoiding substitution for the representation used here, and translate the evaluation rules into constructors.

\[\frac{t_1\to t_1'}{t_1\ t_2\to t_1'\ t_2}\]
\[\frac{t_2\to t_2'}{v_1\ t_2\to v_1\ t_2'}\]
\[\frac{}{(\lambda x.t)\ v\to t[x\mapsto v]}\]
