3. Small-step: expose the computation

The judgment ⟨(a,\sigma)⟩ →ₐ (a') performs one local rewrite. Congruence rules first move the active position through the syntax; computation rules then replace a variable or combine two numbers. The multi-step relation chains those rewrites.

\[\frac{}{\langle x,\sigma\rangle\to_a \sigma(x)}\;\mathsf{Var}\]
\[\frac{}{\langle n_0+n_1,\sigma\rangle\to_a n_0+n_1}\;\mathsf{Add}\]
\[\frac{\langle a_0,\sigma\rangle\to_a a_0'}{\langle a_0+a_1,\sigma\rangle\to_a a_0'+a_1}\;\mathsf{Add\text{-}L}\]
\[\frac{\langle a_1,\sigma\rangle\to_a a_1'}{\langle n_0+a_1,\sigma\rangle\to_a n_0+a_1'}\;\mathsf{Add\text{-}R}\]

The multiplication rules have the same three shapes. A finite run is the reflexive–transitive closure:

\[\frac{}{a\to_a^* a}\;\mathsf{Refl}\]
\[\frac{a\to_a a'\qquad a'\to_a^* a''}{a\to_a^* a''}\;\mathsf{Step}\]

4. Agreement

Theorem

For every arithmetic expression (a), state (\sigma), and integer (n):

\[\langle a,\sigma\rangle\to_a^* n \quad\Longleftrightarrow\quad \langle a,\sigma\rangle\Downarrow_a n.\]

The proof has six parts: facts about multi-step; congruence; big-to-small by rule induction; anti-reduction; small-to-big by rule induction; and the final equivalence. This is also the bridge to the corresponding Homework 3 Boolean proof.

\[ \frac{a_0\to_a^* a_0'}{a_0+a_1\to_a^*a_0'+a_1} \qquad \frac{a_1\to_a^*a_1'}{n_0+a_1\to_a^*n_0+a_1'} \]

For the big-to-small direction, the big-step addition tree determines the three pieces of the run:

\[ a_0+a_1\to_a^*n_0+a_1\to_a^*n_0+n_1\to_a n. \]

The reverse direction is driven by anti-reduction:

\[ \frac{a\to_a a'\qquad\langle a',\sigma\rangle\Downarrow_a n} {\langle a,\sigma\rangle\Downarrow_a n}. \]

Small-step and big-step agree

Theorem: ⟨a, σ⟩ →*a n if and only if ⟨a, σ⟩ ⇓a n.

1. Facts about →*a

A single step is a run: (step) then (refl).

Transitivity, by rule induction on the first run.

2. Congruence, for every rule

The rule AS_Plus_left moves ONE step inside a ⊕: if a1 takes a step, then a1 ⊕ a2 takes the same step, with a2 just along for the ride.

The lemma cong_plus_left does the same for a WHOLE RUN: if a1 runs to a1', then a1 ⊕ a2 runs to a1' ⊕ a2.

Example, with X = 3 and Y = 2:

a1 on its own               inside _ ⊕ const 7
var X ⊕ var Y               (var X ⊕ var Y) ⊕ const 7
const 3 ⊕ var Y             (const 3 ⊕ var Y) ⊕ const 7
const 3 ⊕ const 2           (const 3 ⊕ const 2) ⊕ const 7
const 5                     const 5 ⊕ const 7

Each line on the right comes from the line on the left by AS_Plus_left. The lemma says we can always build the right column from the left one.

Why we need it: in Big ⇒ small, the IH gives a run for a0 on its own, but we need a run for a0 ⊕ a1. This lemma bridges the gap.

Each congruence lemma is rule induction on the run of the subterm. The first is written out; the rest are the same proof with a different rule, so a tactic lift repeats it.

The other congruence lemmas are the same proof with a different rule: AS_Plus_right lets a step happen on the right of a ⊕, once the left side is a number.

3. Big ⇒ small, by rule induction on ⟨a, σ⟩ ⇓a n

If the big-step tree says a evaluates to n, then there is a small-step run from a to n.

Idea: the big-step tree is a recipe, and we follow it one step at a time. To evaluate a0 ⊕ a1, the tree says: evaluate a0 to n0, evaluate a1 to n1, then add. The small-step run does the same, in order:

a0 ⊕ a1  →*  const n0 ⊕ a1          simplify the left side
         →*  const n0 ⊕ const n1    then the right side
         →   const n2               then add

Example, with X = 3 and Y = 2, for (var X ⊕ var Y) ⊕ var X:

(var X ⊕ var Y) ⊕ var X  →*  const 5 ⊕ var X     left side
                         →*  const 5 ⊕ const 3   right side
                         →   const 8             add

Proof: rule induction on the big-step tree, one case per big-step rule. The IH gives us a run for each subexpression ON ITS OWN; congruence puts those runs inside the ⊕, and transitivity glues the three pieces into one run.

4. Anti-reduction

If ⟨a, σ⟩ →a a' and ⟨a', σ⟩ ⇓a n, then ⟨a, σ⟩ ⇓a n. Rule induction on ⟨a, σ⟩ →a a'; in each case, invert the derivation of ⟨a', σ⟩ ⇓a n.

5. Small ⇒ big, by rule induction on ⟨a, σ⟩ →*a n

The (step) rule lets a run end anywhere, so Rocq needs the end point as a separate name a'' with the equation a'' = n.

5. Inversion: use a derivation backwards

apply asks which rule can build the goal. inversion H asks which rule could have built evidence (H). Rocq discards constructors whose conclusions cannot match and returns the premises of every constructor that can.

Inversion

An inductive definition is a list of rules, and those rules are the ONLY ways to build evidence for a fact. There are two ways to use them:

  • Forwards, with apply: to PROVE a fact, pick a rule whose conclusion matches it and prove the rule's premises. This builds a derivation tree from the bottom up.
  • Backwards, with inversion: we are GIVEN evidence H for a fact, and ask "how could H have been built?" Rocq checks every rule whose conclusion could match, keeps only the ones that fit, and in each case gives us that rule's premises. If no rule fits, H cannot exist.
Executable Rocq

Only one constructor can fit

If (H : \mathsf{IsTen}\ n), the sole constructor concludes (\mathsf{IsTen}\ 10). Inverting (H) therefore reveals (n=10).

\[ \frac{}{\mathsf{IsTen}(10)}\;\mathsf{Ten} \qquad H:\mathsf{IsTen}(n)\Longrightarrow n=10. \]

One rule: IsTen

There is only one rule, and it is about 10.

Claim: if IsTen n, then n = 10.

Suppose we are given H : IsTen n. How could H have been built? The only rule is ten, whose conclusion is IsTen 10. So for H to exist, n must be 10.

Notice that we learn this from the EVIDENCE H, rather than by looking at n alone (is it 0? is it 1? ...).

Keep the possible rule; eliminate the impossible ones

For even numbers, inversion can expose the premise of Even_plus2. For even 1, no constructor fits, so inversion closes the impossible case.

\[\frac{}{\mathsf{even}(0)}\;\mathsf{Even\text{-}0}\]
\[\frac{\mathsf{even}(n)}{\mathsf{even}(n+2)}\;\mathsf{Even{+}2}\]
\[ \frac{ \frac{ \frac{}{\mathsf{even}(0)}\;\mathsf{Even\text{-}0} }{\mathsf{even}(2)}\;\mathsf{Even{+}2} }{\mathsf{even}(4)}\;\mathsf{Even{+}2}. \]

Two rules: even numbers

In words: 0 is even, and if n is even, then n + 2 is even.

S n means n + 1, so S (S n) means n + 2. We write the second rule with S (S n) because then Rocq can see, for example, that 4 is S (S 2).

Forwards: 4 is even. We build the tree from the bottom up:

────── Even_0
even 0
────── Even_plus2
even 2
────── Even_plus2
even 4

Backwards: if even (n + 2) then even n.

Suppose we are given H : even (S (S n)). How could H have been built?

  • Even_0 concludes even 0, and S (S n) is not 0. It does not fit.
  • Even_plus2 concludes even (S (S m)) for some m. It fits, with m = n. So H must end in Even_plus2. A rule only applies when its premises hold, so its premise, even n, holds too.

Again, knowing what n is tells us nothing here; only the evidence H contains the fact that n is even.

No rule fits: 1 is not even.

Suppose we are given H : even 1. How could H have been built?

  • Even_0 concludes even 0, and 1 is not 0.
  • Even_plus2 concludes even (S (S m)), which is at least 2, and 1 is less than 2. No rule fits, so H cannot exist. Inversion sees this and finishes the proof.

Back to anti-reduction

If a big-step derivation concludes that (a_1+a_2) evaluates to (n), only the addition rule can have produced it. Inversion exposes the two subderivations and the equation (n=n_1+n_2)—the exact move needed by the agreement proof.

\[ \frac{\langle a_1,\sigma\rangle\Downarrow_a n_1\qquad \langle a_2,\sigma\rangle\Downarrow_a n_2} {\langle a_1+a_2,\sigma\rangle\Downarrow_a n_1+n_2}. \]

Back to big-step semantics

Anti-reduction uses exactly this move. Here is a tiny version of our arithmetic expressions, with just numbers, variables and +, and its big-step semantics.

σ : Var → nat

⟨a, σ⟩ ⇓a n: in state σ, expression a evaluates to n.

Suppose we are given H : ⟨a1 + a2, σ⟩ ⇓a n. How could H have been built?

  • AE_Num is about a number, not a +.
  • AE_Id is about a variable, not a +.
  • AE_Plus is about a +. It fits. So, just as with even (S (S n)), H must end in AE_Plus, and both of its premises hold: a1 and a2 evaluate to some m1 and m2, with n = m1 + m2.

Agreement for commands

The theorem says that the two semantics agree on every terminating command: they reach the same final state even though one hides the intermediate configurations and the other exposes them.

\[ \langle c,\sigma\rangle\to^*\langle\mathsf{skip},\tau\rangle \quad\Longleftrightarrow\quad \langle c,\sigma\rangle\Downarrow\tau. \]

The proof has two directions.

  1. Big-step to small-step. Induct on the big-step derivation. Each big-step rule becomes a finite run. Congruence lemmas let a run for an expression, guard, or first command take place inside the surrounding command.
  2. Small-step to big-step. First prove anti-reduction: if one step takes \(\kappa\) to \(\kappa'\), and \(\kappa'\) evaluates to \(\tau\), then \(\kappa\) also evaluates to \(\tau\). Induct over the whole run and use that lemma once per step.
\[ \begin{aligned} \langle c,\sigma\rangle\Downarrow\tau &\Longrightarrow \langle c,\sigma\rangle\to^*\langle\mathsf{skip},\tau\rangle,\\[4pt] \kappa\to\kappa'\ \land\ \kappa'\Downarrow\tau &\Longrightarrow \kappa\Downarrow\tau,\\[4pt] \langle c,\sigma\rangle\to^*\langle\mathsf{skip},\tau\rangle &\Longrightarrow \langle c,\sigma\rangle\Downarrow\tau. \end{aligned} \]

What to inspect in the Rocq block: step through ceval_multi for the first direction, cstep_antired for the bridge lemma, and multi_ceval for the second direction. The Boolean analogues are admitted here because they are the Homework 3 part; Print Assumptions big_small makes that boundary explicit.
